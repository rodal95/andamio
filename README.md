# andamio

Generador de código para los proyectos de la Tecnicatura: crea proyectos y genera
las partes repetitivas (tablas, menús, recursos de una API, componentes) para que
te concentres en la lógica.

> En desarrollo. Las instrucciones completas de instalación y uso llegan con la versión 1.0.

```
python -m andamio
```
