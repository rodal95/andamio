Cómo funciona

Tres pasos. Lo demás lo escribís vos.

  1. 1

    Instalalo una vez

    Un solo comando, sin configurar nada. Funciona en las PC del laboratorio sin permisos de administrador.

    py -m pip install …andamio.whl
  2. 2

    Creá el proyecto

    Carpetas, configuración y archivos base listos para ejecutar, con el siguiente paso exacto.

    andamio crear react mi-web
  3. 3

    Generá las piezas

    Adentro del proyecto, andamio detecta qué tipo es y genera el código que corresponde.

    andamio nuevo componente Tarjeta

Instalar

Necesitás Python 3.10 o más nuevo. Se instala una sola vez en cada PC.

  1. Abrí CMD o PowerShell (tecla Windows, escribí "cmd" y Enter).

  2. Descarga e instala andamio. No necesita permisos de administrador.

  3. andamio --version

    Si muestra la versión, quedó instalado.

¿Dice que "andamio" no se reconoce? Usá py -m andamio en lugar de andamio: hace exactamente lo mismo. Pasa cuando la carpeta de instalación no está en el PATH de Windows.

  1. Descarga e instala andamio.

  2. andamio --version

Descargá andamio.pyz, guardalo donde quieras (sirve un pendrive) y usalo en lugar de andamio:

py C:\ruta\andamio.pyz crear python mi-tienda

No necesita instalación, ni permisos, ni internet.

Cómo se escriben los comandos

Todos los comandos tienen la misma forma. Este genera un recurso de Django con dos campos:

andamioel programa
nuevoqué hacer
recursoqué pieza
productoel nombre (en singular)
nombre:str precio:decimallos campos (nombre:tipo)
--simularopciones
  • andamio

    Sin nada más, abre un menú que te pregunta todo paso a paso. Es la forma más fácil de empezar.

  • andamio crear <tipo> <nombre>

    Crea un proyecto nuevo: python, django, react o react-native. Con --js, React y React Native se crean en JavaScript.

  • andamio nuevo <pieza> <nombre>

    Adentro de un proyecto, genera una pieza. Funciona desde cualquier subcarpeta.

  • andamio info

    Muestra qué tipo de proyecto detectó y qué piezas podés generar ahí.

  • --simular

    Muestra qué archivos crearía o modificaría, sin tocar nada.

  • --plural paises

    Indica el plural cuando el automático no sirve (andamio arma "productos" solo).

  • andamio plantillas exportar

    Copia las plantillas a tu proyecto para modificar el código que se genera.

Los nombres se escriben como quieras (Línea Venta, linea-venta) y andamio los adapta a cada lenguaje (LineaVenta, linea_venta). andamio nunca sobrescribe un archivo: si ya existe, avisa y no toca nada.

Del servidor al celular, con el mismo comando

Preguntas frecuentes

Dice que "andamio" no se reconoce como un comando.

La carpeta donde se instaló no está en el PATH de Windows. Usá py -m andamio en su lugar: hace exactamente lo mismo.

Dice "No encontré un proyecto".

Tenés que estar dentro de la carpeta del proyecto (o de una subcarpeta). Entrá con cd mi-proyecto, o creá uno con andamio crear.

Mi proyecto de React lo creé con npm create vite. ¿Sirve?

Sí. andamio reconoce cualquier proyecto con Vite y React, y genera TypeScript o JavaScript según el proyecto.

Borré una línea que decía "no borrar esta línea".

No pasa nada grave: andamio genera igual los archivos y te muestra exactamente qué línea pegar y en qué archivo.

Cada guía tiene sus problemas comunes. Más preguntas en el README del proyecto.
