Cómo funciona

Con andamio trabajás con dos cosas: un proyecto (se crea una vez) y sus piezas (las agregás adentro todas las veces que quieras). andamio escribe el código repetitivo; la lógica la escribís vos.

  1. 1

    Instalalo una vez

    Un solo comando en cada PC, sin permisos de administrador.

    python -m pip install …andamio.whl
  2. 2

    Creá un proyecto

    Elegís la tecnología y andamio arma la carpeta con todo listo para ejecutar.

    python -m andamio crear react mi-web
  3. 3

    Generá piezas adentro

    Un componente, una página, un servicio, una tabla con su API… andamio la crea y la conecta (rutas, menú, imports).

    python -m andamio nuevo pagina Contacto
  4. 4

    Combinalas

    Cada guía termina con recetas: un servicio en una página, un componente con datos, un hook propio…

    página + servicio + componente

Cada tecnología tiene su guía paso a paso, con un índice para seguirla en orden. Elegí la tuya ↓

Instalar

Necesitás Python 3.10 o más nuevo. Se instala una sola vez en cada PC. andamio es un programa de Python: por eso todos los comandos empiezan con python -m.

  1. Abrí CMD o PowerShell (tecla Windows, escribí "cmd" y Enter).

  2. Descarga e instala andamio. No necesita permisos de administrador. Si aparece un aviso de que una carpeta "is not on PATH", es normal: no afecta.

  3. python -m andamio --version

    Si muestra la versión, quedó instalado.

Opcional: escribir solo andamio. Ejecutá una vez python -m andamio configurar, cerrá la terminal (y VS Code, si lo usás) y abrí una nueva. Si no, seguí con python -m andamio: funciona siempre.

¿Dice que "python" no se reconoce? Probá con py en lugar de python.

  1. Descarga e instala andamio.

  2. python3 -m andamio --version

    Si muestra la versión, quedó instalado. En Linux y Mac, los comandos de esta página van con python3.

Descargá andamio.pyz, guardalo donde quieras (sirve un pendrive) y usalo en lugar de python -m andamio:

python C:\ruta\andamio.pyz crear python mi-tienda

No necesita instalación, ni permisos, ni internet.

Del servidor al celular, con el mismo comando

Generá un recurso en Django, FastAPI o Express y el servicio (o el CRUD) en React, React Native, Next.js o Reflex con los mismos campos: se conectan sin tocar nada. Las tres APIs responden igual, así que podés cambiar una por otra.

Django · FastAPI · Express python -m andamio nuevo recurso producto nombre:str precio:decimal API en /api/productos/
→
HTML · React · Vue · React Native · Next.js · Reflex python -m andamio nuevo servicio producto nombre:str precio:decimal productoService.listar(), crear(), …

Cómo se escriben los comandos

Todos los comandos tienen la misma forma. Este genera un recurso de Django con dos campos:

python -mPython ejecuta…
andamioel programa
nuevoqué hacer
recursoqué pieza
productoel nombre (en singular)
nombre:str precio:decimallos campos (nombre:tipo)
--simularopciones
  • python -m andamio

    Sin nada más, abre un menú que te pregunta todo paso a paso. Es la forma más fácil de empezar.

  • python -m andamio crear <tipo> <nombre>

    Crea un proyecto nuevo: python, django, django-web, fastapi, express, web, react, vue, react-native, next, next-fullstack o reflex. Con --js, Express, React, React Native y Next.js se crean en JavaScript.

  • python -m andamio nuevo <pieza> <nombre>

    Adentro de un proyecto, genera una pieza. Funciona desde cualquier subcarpeta.

  • python -m andamio info

    Muestra qué tipo de proyecto detectó y qué piezas podés generar ahí.

  • --simular

    Muestra qué archivos crearía o modificaría, sin tocar nada.

  • --plural paises

    Indica el plural cuando el automático no sirve (andamio arma "productos" solo).

  • python -m andamio plantillas exportar

    Copia las plantillas a tu proyecto para modificar el código que se genera.

  • python -m andamio configurar

    Opcional: después de ejecutarlo una vez (y abrir una terminal nueva), podés escribir solo andamio.

Los nombres se escriben como quieras (Línea Venta, linea-venta) y andamio los adapta a cada lenguaje (LineaVenta, linea_venta). andamio nunca sobrescribe un archivo: si ya existe, avisa y no toca nada.

Preguntas frecuentes

¿Por qué los comandos empiezan con "python -m"?

Porque andamio es un programa de Python, y así funciona en cualquier PC. Si preferís escribir solo andamio, ejecutá una vez python -m andamio configurar y abrí una terminal nueva.

Dice "No encontré un proyecto".

Tenés que estar dentro de la carpeta del proyecto (o de una subcarpeta). Entrá con cd mi-proyecto, o creá uno con python -m andamio crear.

Mi proyecto de React lo creé con npm create vite. ¿Sirve?

Sí. andamio reconoce cualquier proyecto con Vite y React, y genera TypeScript o JavaScript según el proyecto.

Borré una línea que decía "no borrar esta línea".

No pasa nada grave: andamio genera igual los archivos y te muestra exactamente qué línea pegar y en qué archivo.

Cada guía tiene sus problemas comunes. Más preguntas en el README del proyecto.
